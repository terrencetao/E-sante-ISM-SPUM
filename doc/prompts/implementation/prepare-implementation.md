# Voici ce qu'il faut faire pour préparer une implémentation

- Vérifier qu'un fichier améliorations (`IPV-XYZ`) a été spécifié.
- Analyser les amélorations nécessaires et prévoir un ou plusieurs fichiers implémentations `implementation/IMP-<ID>-<SLUG>.md`
- Dans chacun de ces fichiers, décrire:
  - les fonctionnalités à modifier,
  - le contexte d'utilisation du programme,
  - les utilisateurs affectés,
  - le résultat attendu,
  - etc.
- ne pas donner de détails d'implémentation, seulement des spécifications du point de vue de l'utilisateur et des contraintes fonctionnelles ou non-fonctionnelles
