## Objectif

  - Apporter des améliorations pour faciliter le travail de développement


## Améliorations nécessaires

### mode développeur

  - ajouter un flag lor du déploiement pour dire si on se trouve en
    - dev
    - staging
    - prod

en mode développement, on ajoute les fonctionnalités suivantes:

- possibilité de basculer entre différents utilisateurs avec une indication visuelle montrant (à tout moment) quel utilisateur nous sommes présentement
- possibiliter de basculer en mode "super utilisateur", c'est à dire avec un utilisateur ayant toutes les permissions.
- possibiliter de réinitialiser les données:
  - de l'application client frontend pwa
  - ou bien de tout le système
